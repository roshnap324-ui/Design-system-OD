## 🚀 Getting Started

### For Designers
1. Start at **home.html** to understand the design system structure
2. Explore **index.html** for detailed component documentation
3. Review **prototype-flow.html** for real-world usage examples

### For Developers
1. Visit **home.html** to understand available components
2. Reference **index.html** for design tokens and CSS classes
3. Check component states and variants in the full design system
4. Copy component code snippets for your implementation
